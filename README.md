# Critical Thinking Tools

一个用于收集、验证和迭代批判性思维工具的项目，重点研究如何帮助人和大模型提出更好的问题，而不只是生成更长的答案。

## 项目假设

大模型通常擅长围绕一个明确问题检索、归纳、比较和验证，却容易在问题尚未成形时过早作答、顺着用户的初始框架推演，或生成大量看似不同但本质重复的问题。

本项目尝试把成熟的提问、反证和决策方法改写成可复用协议：

1. 先扩大问题空间，发现遗漏视角和“未知的未知”。
2. 再收敛到最有信息价值、最可能改变行动的问题。
3. 最后用竞争假设、反方证据、估计或测试进行验证。

这仍是一个需要验证的项目假设。仓库会明确区分“原方法有证据”“只在特定任务有效”和“提示词改编本身尚未测试”。

## 每张工具卡包含什么

- 方法的核心原理与适用阶段。
- 可重复执行的操作流程。
- 可直接复制的大模型提示词。
- 输出质量检查清单。
- 证据状态、适用边界和失败风险。
- 可追溯的论文或机构来源。

工具的“知名”不等于“有效”。例如 ACH 虽被情报分析领域广泛采用，后续实证研究却给出混合甚至偏负面的结果；本项目仍会收录这类工具，但不会隐藏反证。

## 版本约定

项目采用语义化版本号 `MAJOR.MINOR.PATCH`：

- `MAJOR`：包含不兼容的重大调整。
- `MINOR`：新增向后兼容的功能。
- `PATCH`：向后兼容的问题修复或小幅改进。

每次项目更新都应：

1. 更新本 README 中的“版本更新记录”。
2. 提交本次全部相关变更，提交信息应简洁说明更新内容。
3. 将提交推送至 GitHub 远程仓库。
