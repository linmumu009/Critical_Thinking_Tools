# QFT：问题形成技术

- **阶段**：问题生成、改写、排序
- **证据状态**：长期教育实践与新兴研究支持；目前公开证据多含自我报告，因果强度有限
- **适合**：面对主题却不知道该问什么，或模型总是过早进入回答模式

## 一句话原理

把“生成问题”和“评价问题”严格分开：先在不讨论、不回答的条件下尽可能多地产生问题，再转换问题类型、改进和排序。

## 标准流程

1. **设定问题焦点（QFocus）**：用一句陈述、现象或材料作为刺激物；它本身不要写成问题。
2. **连续产问**：在限定时间内尽可能多地提问，不回答、不讨论、不评价，原样记录，把陈述改成问题。
3. **区分类型**：标记开放式与封闭式问题，讨论两类各自优缺点。
4. **转换问题**：至少把一个封闭问题改成开放问题，也把一个开放问题改成封闭问题，观察用途变化。
5. **排序**：依据当前目标选择最重要的三个问题，并说明选择理由。
6. **制定行动**：决定每个优先问题需要什么信息、由谁、何时、用什么方法回答。
7. **反思**：记录这次产问改变了什么理解，以及仍缺什么类型的问题。

## 大模型主持提示词

```text
你是 QFT 主持人，不是答案提供者。严格把“生成”和“评价”分开。

我的问题焦点（它不是问题）是：
[粘贴一句陈述、现象或材料]

第一轮只做产问：
- 从事实、定义、因果、机制、反例、边界、利益相关者、时间、比较、测量和行动角度，生成尽可能多的问题。
- 不回答、不讨论、不评价，也不要合并相似问题。
- 原样编号记录；若出现陈述，把它改成问题。

生成后暂停，等我说“继续”。

我说“继续”后：
1. 标记每题为开放式或封闭式。
2. 选择若干问题进行开放/封闭互换，并说明用途变化。
3. 先问我这轮探索的目标和约束；再按该标准推荐 3 个优先问题。
4. 为每个优先问题给出最小验证计划，但仍不要替我回答问题。
5. 最后反思问题集中缺失了哪些视角。
```

## 质量检查

- 第一轮是否真的没有夹带答案和评价？
- 问题是否覆盖不同认知任务，而非同义改写？
- 排序标准是否来自用户目标，而非模型偏好？
- 优先问题是否可调查、可判别、可行动？

## 局限

- 产量不等于质量；必须经过排序和验证计划。
- 模型批量生成的问题可能高度相关，最好由人补充个人经验与异常案例。
- QFT 对学习者产问能力的证据不能直接证明由模型代为产问有同样效果；更稳妥的用法是让模型主持、人参与生成和筛选。
