# 对抗式协作（Adversarial Collaboration）

- **阶段**：解决长期分歧、联合设计验证、预先承诺
- **证据状态**：有同行评审案例与方法协议；不是保证达成共识的通用实验结论
- **适合**：两方都有成熟观点，继续各写各的论证已经不能推进争议

## 一句话原理

让意见相反的人共同定义分歧、写出可区分预测、预先同意测试与解释规则，并在中立协调者帮助下共同执行和报告。

它与“双向钢人”的区别是：钢人仍可能由一个人代替双方思考；对抗式协作要求真实对手共同确认问题和测试，目标不是让对方输，而是让证据有机会改变双方。

## 操作流程

1. 双方分别写出观点，再互相重述，直到对方认可“被准确理解”。
2. 列出共同同意的事实、价值与定义。
3. 找到真正的分歧点和各自的反转条件。
4. 把分歧改写为不同观点会给出不同预测的“关键测试”。
5. 共同确定数据、样本、指标、排除标准和分析方法；必要时邀请中立协调者。
6. 在看到结果前写下各自预测与如何解释可能结果。
7. 共同执行、分析和发表，包括仍未解决的分歧。

## 大模型辅助提示词

```text
请作为中立协调者，把下面的分歧转成对抗式协作方案。你不能替任何一方宣称立场，也不能强迫虚假共识。

甲方观点：[观点]
乙方观点：[观点]
可用资源/数据：[资源]

请输出：
1. 双方需要相互确认的观点重述草案。
2. 共同前提、定义分歧、事实分歧、价值分歧。
3. 每一方最明确的“什么结果会让我降低信心”。
4. 1-3 个能产生不同预测的关键测试；用表格列双方的预先预测。
5. 双方必须事先同意的数据、指标、排除规则、分析方法和停止条件。
6. 哪些结果仍无法区分观点，以及应如何诚实共同报告。
7. 只提出一个当前最需要双方确认的问题，然后停止。

凡涉及真实研究设计，请标记统计、伦理或领域专家需要复核的部分。
```

## 质量检查

- 双方是否亲自确认了对方的重述？
- 测试是否会在不同观点下产生真正不同的预测？
- 指标与分析是否在看到结果前约定？
- 中立协调者是否能处理权力差异和规则争议？
- 结果是否允许“双方都需修正”或“仍无法判别”？

## 局限

- 当事人若不愿承诺反转条件，流程会退化为表演。
- 权力、资源和专业知识不对称会影响何种测试被选中。
- 单个大模型模拟双方不等于真实对抗式协作；模型的两个角色可能共享遗漏和偏差。
- 实验结果也可能只解决局部分歧，未必改变更广泛理论。
