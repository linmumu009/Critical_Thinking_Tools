# 竞争性假设分析（ACH）

- **阶段**：多解释比较、证据审计、情报式分析
- **证据状态**：著名且经过实证测试，但整体结果混合甚至偏负面
- **适合**：同一组事实存在多个解释，需要留下透明审计轨迹

## 一句话原理

不要逐个寻找支持自己偏好假设的证据，而是把合理的竞争假设同时放入矩阵，优先寻找它们无法同样解释的证据和不一致项。

## 经典流程的实用版

1. 生成互斥程度足够、覆盖主要解释空间的假设集合，并保留“其他/组合解释”。
2. 收集支持与反对各假设的证据和论据。
3. 建立“证据 × 假设”矩阵，逐格判断一致、不一致、中性或未知。
4. 评估证据的**诊断性**：它是否真的区分假设，还是每个假设都能解释？
5. 检查关键证据的可靠性、相关性、是否重复来源以及被操纵的可能。
6. 优先淘汰与高质量证据严重不一致的假设，而不是数支持票。
7. 做敏感性分析：移除一条关键证据后结论是否反转？
8. 写出未来会支持或推翻各假设的指标，并记录未决分歧。

## 大模型辅助提示词

```text
请用 ACH 的结构协助我比较解释，但不要机械打分或宣称它能消除偏误。

分析问题：[问题]
现有材料：[证据与来源]

请：
1. 提出 3-7 个合理竞争假设，说明覆盖缺口，并保留“其他/混合机制”。
2. 建立 Markdown 矩阵：行是原子化证据，列是假设；单元格只填“一致/不一致/中性/未知 + 一句理由”。
3. 为每条证据标记来源独立性、可靠性和诊断性；同源转述不得当作多条独立证据。
4. 找出最能区分假设的证据，以及最依赖主观判断的单元格。
5. 不用简单加总分数替代判断。给出暂定排序时，同时说明先验、关键不一致项和不确定性。
6. 做敏感性分析：删除或反转哪条证据会改变排序？
7. 输出下一步最有信息价值的 3 个观察或调查问题。
```

## 质量检查

- 假设集合是否包含真正替代解释，而非同一故事的小变体？
- 证据是否被拆成独立原子，并检查同源性？
- 是否把“与假设一致”误当成“只支持该假设”？
- 是否公开先验概率和主观矩阵判断？
- 结论是否经受关键证据敏感性测试？

## 为什么必须谨慎

Heuer 的经典说明强调 ACH 的价值在于显式比较假设、关注不一致证据并留下审计轨迹。但后续研究发现：

- 2019 年对 50 名情报分析人员的随机分组研究只发现混合效果，并观察到 ACH 可能增加判断不一致和错误。
- 2024 年一项批判性综述汇总六个实验后认为，完整 ACH 对判断质量几乎没有总体收益，甚至可能有害；其中部分组件仍可能有用。

因此本卡把 ACH 当作**透明的检查清单和讨论界面**，而不是准确率保证。尤其不要把矩阵的简单计数当作贝叶斯更新。
