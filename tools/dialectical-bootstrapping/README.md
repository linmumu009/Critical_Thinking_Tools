# 辩证自举（Dialectical Bootstrapping）

- **阶段**：数值估计、预测校准、第二意见
- **证据状态**：有直接实验支持；主要针对可平均的数值估计
- **适合**：只有一个人或一个模型，却希望获得错误相关性较低的第二估计

## 一句话原理

先做一个估计，再主动假设第一次的推理可能错在哪里，使用不同锚点、知识或方法独立做第二次估计，最后组合两次结果。

普通“再猜一次”常与第一次共享同样错误。辩证自举通过反思第一次的假设并刻意换方法，尝试在同一个头脑里制造更有差异的第二意见。

## 操作流程

1. 不讨论过久，记录第一次数值估计、范围和理由。
2. 暂时把第一次答案封存，列出它可能错的原因：锚点、遗漏变量、基准率、单位、方向或模型。
3. 选择一个不同起点或估计方法，从头生成第二估计。
4. 比较两次方法是否真的不同；若只是换措辞，重新估计。
5. 在没有充分理由偏重一方时取平均；有校准记录时按历史误差加权。
6. 报告组合估计和区间，不抹掉两次估计之间的分歧。

## 可直接复制的提示词

最好在两个隔离上下文中执行 A、B 两段，以降低第二次答案被第一次锚定。

```text
【估计 A】
问题：[需要数值回答的问题]
请先给出一个数值估计、合理区间、使用的基准率和最重要的三个假设。不要生成替代答案。

【估计 B——建议放到新对话】
同一问题：[问题]
请从一个与常见直觉不同的起点独立估计。优先换用另一种方法，例如自下而上改为自上而下、内部视角改为外部基准率、需求侧改为供给侧。给出数值、区间和假设，不参考其他答案。

【组合】
这里有两个估计：[A] 与 [B]。
先判断两者的方法和错误来源是否足够不同，再给出等权平均；只有存在可说明的可靠性差异时才提供加权结果。保留分歧范围，并指出哪项新信息最能缩小区间。
```

## 质量检查

- 第二估计是否真的改变方法、锚点或信息视角？
- 两次答案是否在看见对方之前独立形成？
- 平均是否适用于该量，单位和尺度是否一致？
- 是否报告区间与分歧，而不只报一个精确点估计？

## 证据与局限

Herzog 与 Hertwig（2009）的实验中，参与者先估计历史事件日期，再思考第一答案为何可能错误并给出第二答案；两次答案的平均比单独第一答案更准确，也优于未执行反思的普通第二猜。

该结果不能直接推广到真假命题、价值冲突或不可平均的行动选项。单个大模型的两次输出仍可能共享训练数据与系统性偏差；若条件允许，独立模型、独立人员或真实外部数据更好。
