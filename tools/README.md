# 思考工具索引

这里收录的不是“万能提示词”，而是可以重复执行、可以检查过程、并尽量能追溯来源的思考协议。

## 先选阶段，再选工具

| 阶段 | 工具 | 最适合解决什么 | 证据状态 |
| --- | --- | --- | --- |
| 发现问题 | [QFT 问题形成技术](question-formulation-technique/) | 从一个主题批量产生、改写并排序问题 | 有实践研究；因果证据仍有限 |
| 发现问题 | [STORM / Co-STORM](storm-costorm/) | 用多视角追问和检索发现“未知的未知” | 同行评审系统评估 |
| 深挖问题 | [苏格拉底式追问](socratic-questioning/) | 逐层暴露定义、假设、证据和后果 | 多领域采用；效果依赖引导质量 |
| 公平重构 | [双向钢人论证](bidirectional-steelman/) | 同时强化支持方和反对方，找到真正分歧 | 组合型协议；整体未独立验证 |
| 主动反证 | [考虑相反面](consider-the-opposite/) | 对抗确认偏误和立场固着 | 有直接实验支持，适用范围有限 |
| 结构验证 | [论证地图](argument-mapping/) | 看清主张、理由、反驳和证据缺口 | 有多项教学研究与汇总证据 |
| 假设验证 | [竞争性假设分析](analysis-of-competing-hypotheses/) | 让多个解释同时接受证据检验 | 知名且经过测试，但结果混合/偏负面 |
| 预测校准 | [辩证自举](dialectical-bootstrapping/) | 从不同假设得到第二估计并组合 | 有直接实验支持，主要限于数值估计 |
| 决策验证 | [事前验尸](premortem/) | 在执行前发现失败路径和早期信号 | 广泛采用；核心机制有间接实验支持 |
| 解决分歧 | [对抗式协作](adversarial-collaboration/) | 把观点冲突转成共同认可的可判别测试 | 有同行评审案例；缺少普遍效果保证 |

## 推荐组合

若目标是弥补“大模型不善于提出好问题、但善于验证已有问题”的缺口，推荐按以下顺序使用：

1. 用 **QFT** 批量生成问题，禁止模型过早回答。
2. 用 **STORM / Co-STORM** 引入不同视角与外部检索，发现遗漏主题。
3. 用 **苏格拉底式追问** 把候选问题压到定义、假设和证据层。
4. 用 **双向钢人** 或 **考虑相反面** 生成最强竞争观点。
5. 按任务类型使用 **论证地图**、**ACH**、**辩证自举** 或 **事前验尸** 验证。
6. 当真实的双方长期争论时，用 **对抗式协作** 把争论改写为预测和测试。

## 证据标签怎么读

- **直接实验支持**：至少有研究直接比较使用与不使用该方法的结果，但不代表能泛化到所有领域或大模型。
- **系统/任务评估**：方法作为一个系统在特定基准或用户研究中表现更好。
- **间接支持**：相关心理机制有实验支持，但这里给出的完整流程没有被同样方式验证。
- **混合/偏负面**：已有实证结果不一致，或高质量研究发现效果有限。
- **未独立验证**：适合作为可检验的工作协议，不应宣传为“科学证明有效”。

所有提示词都是对原方法的中文、大模型友好型实现。除非来源明确研究了大模型，否则“对人有效”不能自动推导为“对模型有效”。
