# 双向钢人论证 + 单一关键追问

- **阶段**：问题澄清、公平重构、决策前对抗
- **证据状态**：组合型协议；此完整提示词未发现独立实证验证
- **适合**：用户已有初步立场，但问题边界、反方观点或决策变量尚不清楚

## 一句话原理

先把用户真正要解决的问题说到用户认可，再分别构造正反两方最有力、最可信的版本，最后把争论压缩成一个最可能改变结论的问题。

“钢人”与哲学中的善意解释原则相关：不要攻击最弱版本，而应回应最强且合理的版本。这里的“双向钢人 + 关键变量 + 只问一个问题”是一个组合设计，不是某所大学发布的标准化实验协议。

## 为什么可能适合大模型

普通提示常让模型立即回答，并沿着用户最初框架继续推演。这个协议设置了四个刹车：

1. 先重构问题，检查是不是问错了问题。
2. 强制为双方补强，降低单向迎合。
3. 把抽象争论改写成可改变结论的变量。
4. 在得到关键事实前暂停，不用长答案掩盖信息缺口。

## 操作流程

1. **问题重构**：区分表面提问、实际目标、约束、成功标准和隐含假设。
2. **立场 A 钢人**：给出最强前提、机制、证据类型和成立条件。
3. **立场 B 钢人**：同样强度处理反方；不得只列容易反驳的意见。
4. **分歧压缩**：指出双方共享事实、真正分歧、关键变量和判别性证据。
5. **单一追问**：只问一个回答后最可能改变建议的问题，然后停止。
6. **回答后判断**：给出结论、信心、主要理由、反转条件和下一步行动。

## 可直接复制的提示词

```text
先不要回答结论，也不要默认我已经把问题想清楚。请充当一个公平、严格的思考伙伴，对我的问题执行“双向钢人论证”。

第一阶段：
1. 重述我真正想解决的问题，明确目标、约束、成功标准与隐含假设；把你新增的推断标出来，不要冒充成我的原意。
2. 分别构造支持我当前想法和反对它的最强论证。两边都要包含：核心主张、最强理由、成立条件、需要什么证据；不要制造稻草人。
3. 区分双方已经同意的事实与真正分歧，列出最可能改变结论的关键变量，以及能区分两种观点的证据。
4. 只问我一个信息价值最高的问题。问完立即停止，不给最终建议。

第二阶段（等我回答后再执行）：
5. 给出明确判断、信心水平、主要理由、什么证据会使判断反转，以及一个最小可执行的下一步。

如果问题涉及会变化的事实或专业高风险领域，必须先说明需要查证什么，不得编造证据。

我的问题是：
[粘贴你的问题]
```

## 质量检查

- 用户是否会认可第一步，而不是被模型擅自改题？
- 正反两边是否使用了相同的证据标准？
- “反方”是否真能让支持者犹豫，而不是装饰性异议？
- 最后一个问题是否真的可能改变行动，而不只是补充背景？
- 回答前模型是否按要求停下？

## 局限与风险

- 模型可能替对方发明其从未认可的论点；重要争议应让真实当事人确认钢人版本。
- 两边都说得有力不等于两边证据对称，避免虚假平衡。
- 对事实问题，论证质量不能替代检索、测量或实验。
- 未找到证据表明这段完整提示词本身经过对照测试。
