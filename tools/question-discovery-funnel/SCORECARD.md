# 好问题评分卡

评分卡用于比较已经通过基本门槛的候选问题，不能代替真实试探。

## 一票否决门槛

任一项为“否”时，候选不得进入最终前三：

| 门槛 | 是/否 | 证据或修改 |
| --- | --- | --- |
| 问题的重要性有真实观察、使用者或决策依据，而非模型虚构 |  |  |
| 至少两个合理答案会导致不同判断、优先级或行动 |  |  |
| 问题不预设答案，也不把未经验证的因果关系写成事实 |  |  |
| 能指出至少一种现实可行的回答或试探路径 |  |  |
| 符合伦理、安全、隐私和必要的专业规范 |  |  |

## 相对比较维度

每项使用 0–2 分，并必须写理由。总分只用于候选间讨论，不代表客观概率。

| 维度 | 0 | 1 | 2 |
| --- | --- | --- | --- |
| 决策杠杆 | 无行动变化 | 可能改变优先级 | 不同答案已对应不同动作 |
| 判别力 | 各种解释都能吸收答案 | 能缩小范围 | 能排除或显著削弱竞争解释 |
| 现实相关性 | 仅模型推测 | 有间接信号 | 有一手观察/用户/决策证据 |
| 可回答性 | 无证据路径 | 路径昂贵或信号弱 | 有可执行、可解释的证据路径 |
| 新颖与非冗余 | 已解决或重复 | 扩展已知问题 | 指向未解决且重要的不确定性 |
| 成本收益 | 成本/风险明显过高 | 价值与成本接近 | 可能以低成本避免高代价错误 |
