# Six Honest Serving Men：5W1H 问题构造

- **阶段**：观察展开、问题重构、避免接受初始框架
- **证据状态**：有直接实验支持；研究任务和样本范围有限
- **适合**：拿到一个模糊问题，需要从不同结构角度重新表述后再求解

## 一句话原理

依次用 Who、What、Why、When、Where、How 作为线索重述问题，迫使思考者改变对象、因果、时间、场景和机制，而不只换一种措辞。

名称来自 Rudyard Kipling 的 “Six Honest Serving Men”。在问题构造研究中，它被作为一种结构化认知支架测试。

## 实验发现

Vernon 与 Hocking 的研究将 118 名参与者随机分配到 Six Men、Six Thinking Hats 和一个看似可信的安慰剂式干预组。参与者需在限定时间内以尽可能多的方式重述给定问题。

结果显示，Six Men 组在问题构造的流畅性、灵活性和原创性上优于安慰剂组，也在这些指标上优于或不逊于 Six Hats。研究者强调，没有理由认为这六个词本身具有特殊魔力；更合理的解释是明确结构帮助参与者探索问题。

这是一项范围有限的实验，不能证明它在所有现实领域或大模型上都有效。

## 操作流程

先把原始问题和现实观察分开，然后完成六轮：

1. **Who**：谁经历问题、决定、获益、受损、掌握证据或被遗漏？
2. **What**：实际观察到了什么？预期是什么？“问题”具体指哪个差距？
3. **Why**：为什么它重要？有哪些竞争性原因？当前问题可能只是哪个症状？
4. **When**：何时出现或不出现？是在什么事件之后？时间尺度是否选错？
5. **Where**：在哪些地点、流程、群体或系统边界发生？哪里没有发生？
6. **How**：通过什么机制发生？怎样测量？怎样知道已经改善？

每一轮至少生成两个重述：一个贴近原框架，一个主动改变边界。最后按“实质改变了什么”聚类，删除只换措辞的版本。

## 可直接复制的提示词

```text
不要回答原问题。先使用 Six Honest Serving Men 帮我重构问题。

原始问题：[问题]
已观察到的事实：[只写观察，不写原因]

请依次使用 Who、What、Why、When、Where、How：
1. 每个疑问词提出 2-3 个澄清问题。
2. 每个疑问词生成两个问题重述：一个保持原边界，一个改变对象、边界、因果层级、时间或机制。
3. 把你新增但尚未证实的内容标为“假设”，不要写成事实。
4. 完成后按回答所需的证据或机制聚类，删除仅换措辞的重复项。
5. 选出最能挑战原始框架的三个版本，说明它们分别改变了什么。
6. 不要替我决定最终问题；只问我一个能在三个版本间做选择的关键问题，然后停止。
```

## 质量检查

- 是否真正改变了问题对象、范围、机制或时间，而非语序？
- Why 是否生成了多个原因假设，而不是暗示唯一原因？
- Where/When 是否同时询问了“没有发生”的边界案例？
- How 是否落到可观察机制和测量？
- 重构是否仍然连接真实观察，而不是越想越抽象？

## 局限

- 5W1H 能提高问题构造的多样性，但不能判断哪个问题最重要。
- Why 很容易诱发无证据的因果故事，必须标记假设并外部验证。
- 六类问题可能给人“已经覆盖完整”的错觉，异常、价值冲突和未知利益相关者仍可能缺失。
- 它应位于发散之前；最终选择仍需决策分叉、信息价值和现实试探。
