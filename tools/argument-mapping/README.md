# 论证地图（Argument Mapping）

- **阶段**：论证拆解、证据缺口发现、综合判断
- **证据状态**：有多项教学研究和汇总证据支持；收益依赖训练强度与反馈质量
- **适合**：论点很多、互相嵌套，或模型写出流畅长文却看不出推理链是否成立

## 一句话原理

把散文中的推理转换为可检查的结构：中心主张、支持理由、反对理由、反驳以及每条连接的依据。

论证地图不同于思维导图。思维导图表达“相关”，论证地图必须表达某个命题为何支持或削弱另一个命题。

## 操作流程

1. 把中心问题改成一个可真可假的陈述。
2. 写出直接支持和直接反对中心主张的理由。
3. 判断多个前提是**联合**成立才有力，还是各自**独立汇聚**。
4. 对每个理由继续追问“为什么相信它”以及“即使为真，它与结论有什么关系”。
5. 添加反驳：攻击前提、推理连接或适用边界。
6. 给叶节点附证据、来源和置信度；没有证据的标为待验证。
7. 找出最脆弱且最影响结论的节点，把它改写成下一步问题。

## 文本地图格式

```text
[C0] 中心主张
├─ 支持 [P1] 理由
│  ├─ 支持 [E1] 证据/来源
│  └─ 反对 [O1] 对 P1 的反例或边界
├─ 联合支持 [P2a] 前提 A
│            [P2b] 前提 B
└─ 反对 [O2] 最强反方理由
   └─ 反驳 [R1] 对 O2 的回应
```

## 可直接复制的提示词

```text
请把下面材料转换成论证地图，不要先写总结性长文。

材料：[粘贴文本或观点]

要求：
1. 识别一个中心主张；若材料含多个中心主张，先问我选哪一个。
2. 用编号节点列出直接支持、直接反对、反驳与证据。
3. 明确哪些前提必须联合成立，哪些是独立的汇聚理由。
4. 对每条推理连接分别检查：前提是否可信？即使可信，是否足以支持下一节点？
5. 不补造材料中没有的事实；合理但新增的前提标记为“隐含假设”。
6. 每个证据节点附来源或标记“待验证”。
7. 输出文本树和漏洞表。漏洞表只列：节点、问题类型、对结论影响、下一步验证问题。
```

## 质量检查

- 节点是否都是完整、可判断真假的陈述？
- 支持关系是否被误写成“主题相关”？
- 是否遗漏了使推理成立所需的隐含前提？
- 来源支持的是具体节点，还是仅与主题相关？
- 地图是否指出了最值得验证的节点？

## 证据与局限

Tim van Gelder 汇总的 26 项一学期论证地图教学研究报告加权效应量约 0.7，高强度组约 0.85；作者同时强调这是当时仍在推进的汇总，研究存在异质性，且高质量反馈和熟练教师很重要。该结果支持“学习和反复练习论证地图”，不能直接证明让大模型自动画一次图就会同幅度提高判断质量。

地图会制造清晰感，但清晰结构仍可能建立在错误事实或遗漏选项上；必须独立查证叶节点证据。
