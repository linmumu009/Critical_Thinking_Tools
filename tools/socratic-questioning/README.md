# 苏格拉底式追问

- **阶段**：澄清概念、检查推理、引导自主发现
- **证据状态**：多领域研究和综述总体支持，但研究定义不统一、效果依赖引导质量
- **适合**：已有一个说法或初步答案，需要逐层发现其假设、证据和后果

## 一句话原理

不直接替对方纠错，而是用连续、聚焦的问题，让对方自己说明概念、暴露前提、检查证据、比较视角并修正结论。

## 六类问题

1. **澄清**：你说的 X 具体指什么？什么例子算、什么不算？
2. **假设**：这个判断必须依赖哪些前提？哪个前提最脆弱？
3. **证据与理由**：什么观察支持它？来源可靠吗？还有别的解释吗？
4. **替代视角**：一个理性反对者会怎么看？换一个利益相关者会怎样？
5. **后果与边界**：如果为真，还应观察到什么？在什么条件下失效？
6. **元问题**：我们为什么问这个问题？有没有更上游、更可判别的问题？

## 单步对话提示词

```text
请做苏格拉底式思考教练。你的目标不是展示知识，而是用问题帮助我修正自己的思考。

规则：
- 每轮只问一个问题，并等待我回答。
- 问题应基于我上一轮的具体回答，不要一次列问题清单。
- 依次检查：概念澄清、隐含假设、证据质量、替代解释、反例/边界、后果和元问题；但不要机械轮询。
- 不要用带有预设答案的诱导性问题。
- 如果我给出可查证的事实主张，标记它需要什么证据；不要假装已经验证。
- 每 4 轮简短总结一次：已确认、仍是假设、发生的修正，然后问我是否继续。
- 当出现足以改变行动的关键缺口时，优先追问它。

我当前的说法是：
[粘贴你的判断、计划或答案]
```

## 质量检查

- 问题是在探查用户推理，还是暗中把模型答案塞给用户？
- 是否根据上一轮回答改变追问路径？
- 是否区分了事实、解释、价值判断和行动偏好？
- 是否允许“我不知道”成为有效输出，并把它转成调查任务？

## 局限

- “不断反问”不自动等于苏格拉底法；缺少连续性和方向的提问只会增加负担。
- 引导者可能通过问题措辞操纵答案，心理安全也会影响真实表达。
- 综述指出许多自称苏格拉底式的计算机系统并未实现系统化方法。
- 在医疗、心理、法律等领域，它不能替代合格专业人员的评估。
