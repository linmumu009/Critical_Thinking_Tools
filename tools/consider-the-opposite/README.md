# 考虑相反面（Consider the Opposite）

- **阶段**：反证、去偏、信念更新
- **证据状态**：有直接实验支持；原始实验领域有限，不能保证所有任务都有效
- **适合**：已经形成偏好、解释或结论，担心自己只寻找支持证据

## 一句话原理

与其泛泛提醒“保持客观”，不如具体假设当前判断可能错了，并生成能解释相反结论的理由、证据和可观察预测。

Lord、Lepper 与 Preston（1984）的两个实验发现，诱导参与者考虑相反可能性，比仅要求“公平、无偏”更能纠正特定社会判断中的偏差。

## 操作流程

1. 写下当前结论和信心（0–100%）。
2. 明确它的相反命题；避免把“不是 A”偷换成一个过窄的 B。
3. 假设相反命题为真，生成至少三条彼此不同的因果解释。
4. 对每条解释写出：应看到什么证据、什么证据会削弱它。
5. 主动寻找区分正反命题的诊断性证据，而非双方都能解释的事实。
6. 查看证据后重新给出信心，并说明变化来自哪一项信息。

## 可直接复制的提示词

```text
请使用“考虑相反面”方法检查我的判断，不要只提醒我保持客观。

当前判断：[判断]
当前信心：[0-100%]
已有证据：[证据]

请：
1. 精确写出当前判断及至少两个合理的竞争命题。
2. 暂时假设当前判断是错的，为每个竞争命题构造最可信的因果解释。
3. 分别列出：若该命题为真应观察到什么、什么观察会削弱它。
4. 找出最多 3 项诊断性最强的信息：它们在不同命题成立时出现概率应明显不同。
5. 区分已有事实、推断与待查证项；需要实时或专业事实时先检索可靠来源。
6. 在新证据出现前不要替我更新信心；先问我是否要提供或查找这些信息。
```

## 质量检查

- 相反命题是否合理、完整，而不是荒谬极端？
- 生成的是可区分预测，还是只换了一套故事？
- 是否同时规定了“支持”和“削弱”条件？
- 新信心是否真的随证据变化？

## 局限

- 强制想象相反面可能产生貌似合理但没有根据的故事。
- 原始研究支持的是特定判断偏差的纠正，不代表在所有领域、所有人或所有大模型上同样有效。
- 当一个命题本来就有压倒性证据时，不应制造虚假平衡。
