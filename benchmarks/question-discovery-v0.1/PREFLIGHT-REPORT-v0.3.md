# Benchmark v0.3 反事实成对预检报告

日期：2026-08-19  
模型：本地配置的 API 模型  
随机种子：11  
调用：4 个公开案例 × 3 个提示条件 = 12 次，仅提问前判断

## 结论

反事实成对结构通过提问前天花板预检，可以进入“小规模成对提问校准”，但尚不能启动正式效果实验。

模型对每个公开案例只作答一次，同一回答分别按两个隐藏分支计分。由于两个分支的最佳行动不同，12 次回答均只命中 1/2 个分支，总成对准确率为 0.500。相比 v0.2 的 12/12 提问前命中最佳行动，新结构成功消除了固定答案天花板。

## 汇总指标

| 指标 | 结果 |
|---|---:|
| API 调用 | 12 |
| 提问前成对准确率 | 0.500 |
| 两个分支行动的概率总量均值 | 0.721 |
| 两个分支行动的概率差均值 | 0.159 |
| 协议失败 | 0 |

模型平均把 72.1% 的概率分配给两个真正可能成为最佳的分支行动，说明公开案例的主要决策分叉可识别。平均分支概率差为 15.9 个百分点，说明模型仍有先验偏好，但没有达到“提问前已经知道答案”的程度。

## 按条件描述（不可作效果排名）

| 条件 | 成对准确率 | 分支概率总量均值 | 分支概率差均值 |
|---|---:|---:|---:|
| A：基线 | 0.500 | 0.725 | 0.150 |
| B：双向钢人 | 0.500 | 0.738 | 0.138 |
| C：发现漏斗 | 0.500 | 0.700 | 0.190 |

这里没有提问与 Oracle 信息，三个条件的差异只反映初始框架对先验概率的轻微影响。每组只有 4 个公开案例，不能推断哪种提示更有效。

## 通过了什么

1. 同一成对案例的两个隐藏分支具有完全相同的公开载荷。
2. 模型看不到分支名称、隐藏事实、效用或另一个世界。
3. 每对最佳行动不同，8 个最佳位置在 A/B/C/D 间均衡。
4. 提问前成对准确率符合理论上限 0.5。
5. 12 次 API 输出全部满足选择与概率协议。

## 尚未证明什么

- 没有证明任何提示条件能提出更好的问题。
- 没有证明提问后能正确区分两个隐藏世界。
- 没有完成独立 Oracle 或双盲人工问题评分。
- 没有测量跨种子、跨模型稳定性。

## 下一步

先实现成对完整运行与成对计分，再做每个领域一对、每个条件一次的小规模校准。核心指标应是提问后两个隐藏世界的概率是否朝相反且正确的方向分离，而不是单个案例的事实命中数。

只有当提问后分支区分优于提问前，Oracle 审计通过，并且盲评认为问题具有决策相关性和分叉辨别力时，才扩展案例和种子。
