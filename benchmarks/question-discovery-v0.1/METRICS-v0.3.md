# Benchmark v0.3 成对指标

## 比较单位

最小比较单位是 `公开案例 × 隐藏分支对 × 条件 × 模型种子`。

同一个公开案例在两个隐藏世界中分别运行。两次运行使用相同模型、条件、种子、公开载荷和问题预算，只有 Oracle 固定事实不同。条件比较必须在相同案例与种子内配对，N 条件是主要对照。

## 四个条件

| 条件 | 含义 |
|---|---|
| N | 原生模型；只有逐轮输出协议，无思考工具和问题质量指导 |
| A | 普通提问基线；明确要求通过提问改善决策 |
| B | QFT、STORM、双向钢人串联 |
| C | 问题发现漏斗 |

N 不是完全没有系统消息：API 实验必须提供格式和轮次控制。它是“协议以外不增加思考方法”的最小干预对照。

## 主指标：反事实分支概率分离增量

设两个隐藏世界的最佳行动分别为 `a` 和 `b`，模型在世界 1、世界 2 中给行动 `x` 的概率分别为 `p1(x)`、`p2(x)`：

```text
separation = 0.5 × [(p1(a) - p2(a)) + (p2(b) - p1(b))]
counterfactual_separation_gain = post_separation - pre_separation
```

解释：

- `0`：两个隐藏世界的概率没有朝不同方向移动；
- 正值：模型根据获得的信息，更偏向各自世界的正确行动；
- `1`：两个世界都把全部概率放在各自正确行动上；
- 负值：提问使两个世界朝错误方向分离。

选择它作为主指标，是因为它直接测量问题是否帮助模型区分公开信息相同、答案相反的两个世界，并扣除了提问前已有的随机差异或先验偏置。

## 次要结果指标

- `post_choice_accuracy`：两个隐藏世界最终选择正确行动的比例。
- `both_post_decisions_correct`：两个世界是否都选对；只有 0 或 1。
- `correct_option_probability_gain`：各自正确行动的平均概率提升。
- `post_decisions_diverge`：两个世界的最终行动是否不同。不同是必要但不充分条件，因为也可能分向错误行动。
- `mean_probability_quality_improvement`：两个世界 Brier 式概率质量改善的均值，用于与 v0.2 衔接。

## 问题质量驱动指标（人工盲评）

每个问题分别标注：

- `decision_relevance_0_to_2`：是否直接关系当前行动选择；
- `branch_discrimination_0_to_2`：不同答案是否会支持不同隐藏分支或行动；
- `specificity_0_to_2`：对象、指标、时间或比较是否足够具体；
- `data_gap_value`：没有固定答案时，问题是否仍揭示值得采集的数据缺口。

问题质量评分不能由知道条件或最佳行动的评审者单独完成。正式比较至少要隐藏条件标签，并报告评分一致性。

## 护栏

- `mean_questions_used`：交互长度与成本。
- `mean_no_fact_answer_rate`：事实覆盖和无效往返的混合指标，不能单独判定问题质量。
- `protocol_deviation_count`：输出协议稳定性。
- Oracle 匹配不一致与人工审计错误：正式实验必须单独报告。
- API 调用量与模型成本：N/A/B/C 使用相同问题上限，不允许某条件获得更多事实预算。

## 运行门槛

1. 先对一个案例的 N 条件完成成对烟雾测试，确认两个会话可保存并生成成对指标。
2. 再运行 4 个案例 × 4 个条件 × 1 个种子的 16 个成对校准单元，共 32 个模型会话。
3. 该 16 单元只用于检查方向、异常、Oracle 和成本，不进行显著性结论。
4. 跨条件效果比较至少增加多个种子，并在运行前固定汇总规则；正式样本量需根据校准方差另行确定。
5. N 是主要对照；A 用于区分“仅鼓励提问”和“具体思考工具”的增量。
