# Benchmark v0.3：N/A 两种子确认报告

日期：2026-08-19  
模型：qwen3.8-max  
模型种子：1、2  
范围：4 个反事实案例 × N/A × 2 个隐藏分支 × 2 个种子  
有效样本：16 个成对单元、32 个模型会话

## 总体评估：可带限制分享

第二个种子保留了 A 普通提问相对 N 原生模型的总体优势，但优势明显缩小，并出现一个反向案例。跨两个种子，A 的反事实概率分离增量均值为 `+0.532`，N 为 `+0.398`；在 8 个“案例 × 种子”配对中，A 有 7 个高于 N，平均案例内差值为 `+0.134`。

这支持把 A 保留为当前首要候选和后续工具的强基线，但仍不足以宣称“普通提问已被证明优于原生模型”。只有 4 个合成案例，两个种子复用了同一案例与同一模型 Oracle；项目案例还从种子 1 的 A 优势 `+0.380` 反转为种子 2 的 N 优势 `+0.330`，说明提示效果可能受生成波动和问题路径影响。

### 稳定信号

1. A 的跨案例均值在两个种子中非常接近：`+0.535` 与 `+0.529`。
2. 运营案例两次都明显支持 A，A − N 分别为 `+0.315` 与 `+0.430`。
3. 产品案例在种子 2 中两种条件都只问一个问题并实现双分支正确，说明原生模型在关键分叉清晰时可以与普通提问持平。
4. A 在 8 个配对单元中 7 个高于 N，并把双分支全对从 4/8 提高到 7/8。

### 不稳定信号

1. A 的平均优势从种子 1 的 `+0.204` 缩小到种子 2 的 `+0.064`。
2. 项目案例发生方向反转：种子 2 中 A 的两个隐藏分支都围绕事实表无法回答的登录统计追问，最终没有区分相反行动；N 至少在一个分支命中权限与活跃率证据。
3. N 的主指标均值从 `+0.331` 升至 `+0.465`，说明原生提问路径本身具有较大运行波动。
4. A 的平均无答案率没有优于 N；它的优势来自更常命中能改变行动的关键事实，而不是普遍减少不可回答问题。

## 验证报告

### 总体判断：可带限制分享

- 种子 2 的进度账本包含 8 个唯一结果文件和 16 个唯一会话，N/A 各 4 个成对单元，四个案例均完整覆盖。
- 16 个会话均为 Benchmark v0.3、qwen3.8-max、模型种子 2、`semantic_api` Oracle。
- 从原始会话重新计算全部种子 2 成对指标，与保存结果最大差异为 0。
- 种子 2 的协议偏离总数为 0；会话与结果目录中未发现 API Key 或 Bearer 凭证字段。
- 最后一个项目 A 单元曾在生成最终判断时中断；进度账本未记录该半成品，随后从两个隐藏分支完整重跑。报告只使用完整重跑结果。

### 必须保留的限制

1. 四个案例是人工构造的开发集，不代表真实用户问题分布。
2. 两个种子共享案例，不是 8 个独立案例；均值容易被项目案例等单一任务影响。
3. 服务端即使接收 seed，也不保证完全确定；这里测到的是提示条件与运行波动的组合。
4. Oracle 复用受测模型，可能偏好相似措辞；正式比较仍需独立 Oracle 或条件盲人工复核。
5. 无答案率同时反映提问质量与固定事实覆盖，不能单独作为好坏判断。
6. 当前只确认 N 与 A；B 的高峰值和 C 的改版尚未进入多种子确认。

## 决策与下一步

1. 保留 A 为当前默认问题发现提示和所有复杂工具必须击败的强基线。
2. 继续运行种子 3 的 N/A 配对；预先保持同一案例、指标与随机计划，不因种子 2 结果改提示。
3. 种子 3 后以案例为聚类单位报告三种子分布，不把重复种子误当成独立案例扩大把握度。
4. 对全部问题导出隐藏条件盲评包，人工评价决策相关性、分叉辨别力、具体性和数据缺口价值。
5. 在扩大案例集前，先增加真实用户问题并为每个问题构造可审计的相反世界；正式研究改用独立 Oracle。

当前结论应表述为：**在 4 个反事实开发案例的两个种子中，普通提问相对原生模型呈现方向一致但幅度不稳定的总体优势；它是当前最强基线，不是已被证明的普遍最佳方法。**
