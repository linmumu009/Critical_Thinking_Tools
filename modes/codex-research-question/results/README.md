# 模式 2 正式结果

每次完成的研究问题发现会话保存在本目录，并随对应版本提交。建议文件名使用 `YYYY-MM-DD-主题.json`，同时提供一份便于阅读的同名 Markdown 报告。

只有通过 `research_question_session.py validate --complete` 的 JSON 才能标记为完整结果。会话中的来源链接和论文判断仍需在运行时由当前 Codex实际核验；结构验证通过不等于研究结论已经被实验确认。
