# 模式 2 研究问题发现报告：语义等价 Prompt 倍率的不变性

## 结论先行

- 执行方式：模式 2，`current_codex`；未读取或调用外部模型 API。
- 决策期限：2026-09-12。
- 决策对象：是否投入 1–2 个工程周和小模型 GPU，建设 family provenance、族级审计和 family-normalized RLVR。
- 当前结论：只批准 24–32 个金标准问题族的缓存 rollout/短程更新最小探针，不批准直接进入完整训练。

主问题：

> 在固定潜在数学问题族、验证标准、总 rollout token 和全局更新预算时，仅把随机一部分问题族扩成 4×/8× 经验证语义等价的 prompt 变体，prompt-uniform RLVR 是否会因族大小产生可重复的更新偏移与 family-heldout OOD 变化；按族归一化能否恢复对变体倍率的不变性？

这个问题得分 12/12，通过全部五项硬门槛。它的关键增量不是再次证明“去重、多样性或难度重要”，而是把潜在问题族集合保持不变，只随机改变部分族的等价表述数，观察 prompt 数是否被 RLVR 当成了额外独立证据，再用族归一化做恢复性干预。

## 现实信号与未解张力

本轮纳入 12 项一手论文信号：

1. [DEPO](https://arxiv.org/abs/2509.01321) 和 [SGAC](https://arxiv.org/abs/2605.01823) 从 prompt 难度、可探索性与训练动态出发提高 RLVR 数据效率，但分析单位主要仍是单个 prompt。
2. [BV-Blend](https://arxiv.org/abs/2606.28707) 使用语义簇级统计选择数据，是最接近“潜在族”视角的工作；尚未随机操纵等价变体倍率或检验族归一化的不变性。
3. [Problem Paraphrasing](https://aclanthology.org/2025.ijcnlp-long.23/) 显示同一问题的改写并非价值完全相同的机械副本，提示“等价”必须用答案、运算结构和人工/程序核验定义，而不能只靠 embedding。
4. [FLAMES](https://arxiv.org/abs/2508.16514) 强调合成数学数据的覆盖价值，[SPARQ](https://arxiv.org/abs/2506.06499) 则区分难度对域内收益与多样性对 OOD 的作用；两者共同说明原始 prompt 数不是独立覆盖的可靠代理。
5. [Self-Error-Instruct](https://aclanthology.org/2025.acl-long.417/) 通过自生成错误与修正扩展监督，但没有回答多个表面变体应算多少个训练单位。
6. [When Can LLMs Learn to Reason with Weak Supervision?](https://arxiv.org/abs/2604.18574) 讨论弱监督条件与饱和边界；[The Invisible Leash](https://arxiv.org/abs/2507.14843) 和 [Beyond pass@k](https://arxiv.org/abs/2605.28022) 提醒高表面 reward/pass@1 可能伴随探索或支持收缩。
7. [Multilingual Verifier Bias](https://arxiv.org/abs/2608.20362) 表明输入条件变化可改变 verifier 假阴性，因此本轮把 verifier disagreement 设为竞争解释，不把所有变体差异归因于策略学习。
8. [Reasoning or Memorization?](https://arxiv.org/abs/2507.10532) 显示污染与记忆可能伪装成推理增益，因此主要评测采用按潜在问题族留出，而不是随机 prompt 留出。

共同张力是：近期工作已分别证明 prompt 权重、语义簇、覆盖、难度、表述和 verifier 条件都可能影响训练价值，却仍不知道同一个潜在问题被生成器改写得更多时，prompt-uniform 是否会把“表述生产力”误当成“独立证据量”。

## 主问题契约

### 边界

- 潜在问题族必须同时满足最终答案、关键运算/概念结构一致，并由程序检查或人工双审确认；embedding 相似不能单独定义金标准族。
- 语义等价变体只改变措辞、顺序或表面情境，不改变知识要求、运算图、答案空间或 verifier 条件。
- 预注册随机选择扩增族，把可见 prompt 数从 1× 改为 4×/8×；问题族集合、全局 rollout/update token、模型初始化、优化器和验证标准固定。
- 主要结果是族级梯度质量、相对 family-uniform oracle 的更新 cosine/误差，以及未见问题族和未见表述 OOD；训练 reward 只作辅助量。
- 恢复干预是每个 prompt 权重除以金标准族大小，并与 prompt-uniform、精确去重和难度匹配比较。
- 首轮只覆盖程序可验证的合成数学题、1–3B 小模型、两种变体生成器和至少三随机种子，不外推到开放式偏好奖励。

### 竞争答案与行动

- A：倍率产生随 1×/4×/8× 增长的更新偏移和可重复 OOD 变化，族归一化显著恢复。行动：记录 family ID，推进归一化采样，并转入 C09 的失效边界研究。
- B：倍率效应接近零、仅改变方差，或归一化无法恢复且带来更大损失。行动：停止通用族归一化开发，把预算转向独立覆盖、难度课程或 verifier 质量。
- 未知：效应只在特定难度、verifier disagreement、记忆水平、生成器或低异质族出现。行动：只在该边界内使用，补做金标准族和第二生成器复现。

### 最小探针

1. 取 24–32 个金标准数学问题族，每族 8 个可信 verifier 通过的表述变体。
2. 预注册随机一半为扩增族，构造 1×/4×/8× 三个 prompt 索引，但不增加全局 rollout token。
3. 复用同一 1–3B 基模的缓存 rollout，三种子重放 prompt-uniform 与 family-normalized 的 50–200 步更新。
4. 比较扩增族梯度质量、相对族均匀 oracle 的梯度 cosine/误差，以及未见问题族和未见表述准确率。
5. 同时匹配基模成功率、长度与难度，替换可信 verifier，并记录 verifier disagreement 和记忆探针，排除竞争解释。

最低保留条件是：至少两种子和第二生成器出现预注册剂量反应，且族归一化把主要梯度偏差或 OOD 差异缩小至少一半。若无剂量反应、符号跨种子不稳，或归一化不优于难度匹配/精确去重，则在先导阶段停止。

## 两个备选

### C07：族级留出的排名反转预警

> 在合成数学数据的短程 RLVR 方法比较中，随机 prompt-heldout 与按潜在问题族/生成模板留出的验证曲线在什么可观测条件下给出相反方法排名；family-heldout 能提前多少更新步预警记忆或变体泄漏导致的最终无泄漏 OOD 失败？

如果主问题的数据族构造或训练预算受阻，C07 可直接复用既有检查点和生成 provenance。它只保留“排名反转条件与提前量”这一非显然增量，不再把一般防泄漏原则包装成新问题。

### C09：族归一化的错权阈值

> 当语义族内梯度异质度、聚类误差或 verifier 条件差异升高时，family-normalized 抽样相对 prompt-uniform 会在什么可观测阈值后由去偏变成错权；该阈值能否跨生成器迁移并在更新前安全路由？

如果 C01 显示族归一化确有收益，C09 是最直接的下一问。它以人工注入 0/10/20/40% 拆并错误和族内异质度分层寻找 crossover；只有冻结阈值在第二生成器 AUROC 至少 0.75 且降低最坏误路由损失时才保留。
