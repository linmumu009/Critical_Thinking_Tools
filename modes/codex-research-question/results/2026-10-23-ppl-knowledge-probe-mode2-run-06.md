# 模式 2 正式运行 06：是词变生疏了，还是关系忘了？

日期：2026-10-23。当前 Codex 执行共享漏斗阶段 0–8；不是外部模型 API 运行。

用户线索是“多任务联合训练中，将预训练损失/PPL与知识探针结合；复述概率低，但仍能辨认”。这是一条尚待操作化的研究线索，本轮没有收到对应模型、检查点或概率日志。

## 先把原始想法拆清楚

PPL 本来就由条件概率计算：`PPL = exp(平均 token 负对数似然)`。训练中通常优化交叉熵 CE；“换验证指标”和“换训练目标”需要分别讨论。

“术语本身概率低”可用领域和格式匹配、但不指明目标主体的参考上下文近似测量；它不是从模型里直接读出的纯边际概率。给定问题的答案概率还受关系线索、提取方式、答案别名和分词影响。不能把两者看作互斥原因。

| 要分清的对象 | 可以先看什么 | 不能直接推出什么 |
| --- | --- | --- |
| 普通文本是否仍容易预测 | 固定语料 CE/PPL | 每个事实都被保住 |
| 答案词项是否容易输出 | 参考上下文下的答案偏好 | 模型懂不懂具体关系 |
| 上下文是否支持正确关系 | 正确/错误答案对比、匹配主体差分 | 已分离出“纯知识” |
| 用户能否实际调用知识 | 未见问法的自由生成与辨认，分别评估 | 内部一定存在或不存在某个事实 |

“探针”也有三个不同对象：固定行为题、隐藏层分类器、参与训练的辅助损失。主问题先研究第一种，两个备选分别覆盖后两种。

## 主问题：先验校正能否改善训练排序

**白话：剔除答案本身的偏好后，探针能更准地选出保住事实的训练方案吗？**

**正式核心：答案先验校正能否提高知识探针对多任务训练方案跨问法事实保持的排序一致性？**

若能，应先校准监测器，再用它选任务配比或检查点；若不能，保留原始对比 probe 与通用 CE，避免为校正增加复杂度。这比直接决定“用 probe 替换 PPL”更靠近当前需要验证的未知。

次级问题分开处理：机制是词项偏好漂移是否中介排序变化；边界是长尾答案、关系类型和参考提示；干预是领域 PMI 与匹配主体差分的选择。

### 一个具体的诊断例子

设正确答案为 a、同类型错误答案为 b，定义：

```text
M(q) = log p(a | q) - log p(b | q)
C(q) = M(q) - M(q0)
D    = M(q_s) - M(q_s')
```

q0 是参考上下文；q_s 与 q_s' 是同关系、已知答案相反的匹配主体，例如两座国家的首都问题使用同一组城市答案。它们不是把真实证据随机打乱后默认真值不变。

已执行的二元 logit 反例中，`M = 答案偏好 b + 关系信号 k`：

| 条件 | 正确答案概率 | 原始 M | 参考校正 C | 匹配主体差分 D |
| --- | ---: | ---: | ---: | ---: |
| 初始 b=0，k=2 | 0.881 | 2.0 | 2.0 | 4.0 |
| 只改答案偏好 b=-4，k=2 | 0.119 | -2.0 | 2.0 | 4.0 |
| 只损伤关系 b=0，k=0.5 | 0.622 | 0.5 | 0.5 | 1.0 |

这个反例只证明：在已知加性机制里，原始概率下降不足以判定关系信号受损。**它不证明真实模型具有这种分解，也不证明校正能改善真实训练方案排序。** 偏好变化若确实使用户更难得到答案，校正还可能掩盖真实的可用性退化。

## 已有工作覆盖了什么

本轮不把以下内容当新颖性：

- [KR-Test（2026）](https://arxiv.org/abs/2601.03505) 已用正确/错误续写的似然对比补充 PPL，并分析 LoRA 训练动态。
- [Dissecting Learning and Forgetting（2024）](https://proceedings.iclr.cc/paper_files/paper/2024/file/c4de749a4bd8802f0b4033d09a7867db-Paper-Conference.pdf) 已拆分主题、风格与事实变化；其分解明确依赖近似假设。
- [Surface Form Competition（2021）](https://aclanthology.org/2021.emnlp-main.564/) 已提出领域条件 PMI；[后续反证（2023）](https://aclanthology.org/2023.emnlp-main.522/) 表明归一化可能无效或有害。
- [Inside-Out（2025）](https://arxiv.org/abs/2503.15299) 和 [Empty Shelves or Lost Keys（2026）](https://arxiv.org/abs/2602.14080) 已研究内部可读、辨认与生成之间的差距。
- [Persistent Calibration（2026）](https://arxiv.org/abs/2609.38797) 已研究校准器跨检查点失效。因此，动态校准本身也不能作为创新声明。

本轮保留的增量是：**先验校正对“训练方案事实保持排序”的有效性**，而非重新发明概率归一化。三路检索未找到直接完成该比较的答案，处置为 `incremental / narrow`，不是“尚无人研究”的证明。

## 最小下一步与完整契约摘要

建议先离线评估已有检查点：96 个人工核验事实、每个三种问法，覆盖三种任务配比、三个随机种子。没有现成检查点时，先确认模型与训练预算，不能把这个规模当成已有数据。

1. 按事实族和实体划分训练约束、校准及评测，冻结同类型困难负例和答案别名。
2. 固定 tokenizer、完整答案 span、前导空格和终止边界。多 token 答案以完整总 logprob 为主；先匹配长度，按 token 均值只作敏感性分析。
3. 同时报告普通 CE、原始 M、领域参考校正 C、匹配主体差分 D，以及未见问法的生成与辨认保持。D 不充当真值。
4. 比较各指标对独立评测下训练方案成对排序的一致率，按事实族进行 bootstrap；并用已知偏好干预、关系扰动正负对照检查归因。
5. 前瞻推进规则：校正比原始指标的一致率至少提高 0.10、区间排除 0、不同参考提示方向一致才继续。不是功效分析，也不是当前实验结果；若样本不足以判断，不宣称胜出。

A 成立则建设校准监测器；B 成立则保留简单双指标；混合结果只在有效关系族使用。若校正不稳定、表现更差或只提升辨认而损害生成，则停止把它用于配比控制，保留生成可用性指标。当前未批准直接删除预训练 CE。

规划节点建议为 2026-11-06，并非用户已承诺期限。本轮无外部模型调用或 GPU 训练。后续优先公开/人工事实与已有缓存；模型、任务和算力仍未确定。KR-Test 论文给出的实现链接本轮打开返回 404；未下载数据或核查其许可，不声称实现已复现。
