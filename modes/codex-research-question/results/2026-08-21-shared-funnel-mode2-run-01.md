# 模式 2 正式运行 01：闭环验证器复用偏差

日期：2026-08-21  
执行引擎：当前 Codex（模式 2）  
共享流程：阶段 0–8；与模式 1 相同，只替换引擎和适配提示词

## 结论先说

本轮最值得研究的问题是：

> 在迭代式合成数据后训练中，当同一个验证器被反复用于样本筛选、课程选择和停止判断时，模型在独立验证器与分布外任务上的真实增益会随轮次下降多少；在相同验证预算下，把这三个角色分离并在不同模型家族间轮换，能否阻止这种闭环过拟合？

通俗地说：我们不断让同一个“老师”出题、判作业、决定学什么，还让它判断什么时候毕业。分数越来越高，可能只是学生越来越懂这位老师的口味，并不一定真的变强。这个研究要测清楚这种假进步是否存在，以及“换老师、分开职责”是否值得额外复杂度。

它与工作簿已有问题的区别是：

- 不是问验证器静态准确率高不高；
- 不是问策略会不会直接 reward hacking；
- 不是问验证器随策略变化是否校准；
- 而是问多轮数据闭环对同一验证器的**适应性复用**是否产生累积偏差，并比较等预算的角色隔离方案。

## Stage 0：冻结决策目标

- 使用者：做文本后训练、合成数据和 GRPO/RLVR 的研究者。
- 要做的决定：下一项低成本试验优先投在哪个研究问题上。
- 决策期限：一周内能够启动最小试验。
- 约束：先用 1B–7B 开放模型、小规模数据和现成验证器；不依赖人工逐候选评分；不调用外部模型 API。
- 停止条件：至少 8 个候选经过一手来源碰撞、硬门槛、双向钢人与廉价试探，最后留下 1 个主问题和 2 个备选。

## Stage 1：现实信号

本地工作簿包含 42 个已整理空白、940 个核心问题、5,608 篇完整文献和 240 篇 2026 arXiv 条目。逐条对照后，异步陈旧、replay、动态 group size、验证器漂移、数据坍缩、验证器冲突等方向已被占用，不能换名重复推荐。

本轮用于推理的关键一手信号如下：

| 信号 | 一手结果 | 对本轮的含义 |
|---|---|---|
| Escaping Model Collapse via Synthetic Data Verification | 验证筛选短期降方差，但多轮后会收敛到验证器的“知识中心” | 多轮复用可能累积验证器偏差 |
| Towards Active Synthetic Data Generation | 依据当前学生状态闭环生成比静态生成更高效 | 合成数据流程确实越来越自适应，复用风险更现实 |
| Beyond Solving | 跨模型家族验证优于同家族/自验证，且后训练改变 verifier gain | “换家族”不是装饰变量，而是可检验干预 |
| LLMs Gaming Verifiers | RLVR 会利用验证器未约束的等价类；同构扰动能暴露捷径 | 独立、变换后的评分可作为盲测 |
| Scaling Laws for Reward Model Overoptimization | 代理分数继续上升时，真实质量可能平台或下降 | 需要把闭环分数和独立分数分开 |
| Adaptive Data Analysis and Holdout Reuse | 反复、适应性使用同一 holdout 会过拟合 | 给出了跨领域的统计机制，但尚未直接落到 LLM 合成后训练闭环 |
| RLSVR | 任务变换能把开放任务变成可验证代理环境 | 未来更多训练会依赖代理任务，代理复用偏差会更重要 |
| Gradient Regularization | 奖励准确率与优化区域平坦度相关，显式正则可缓解 hacking | 提供了不同于角色隔离的竞争机制 |
| Representation Collapse | 连续后训练会压缩表征并损害未来可塑性 | 说明多轮退化也可能来自表征，而不全是验证器复用 |

## Stage 2：5W1H 与苏格拉底重构

### 5W1H

- What：同一验证器跨轮次、跨角色复用是否造成独立质量与闭环分数脱钩。
- Why：若存在，更多合成数据或更严格过滤可能放大假进步；若不存在，复杂的多验证器方案只是浪费成本。
- Who：数据合成管线设计者、后训练研究者、验证器/奖励模型研究者。
- When：从第几轮开始出现？是否在学生接近验证器能力边界时才出现？
- Where：数学/代码等可执行任务与开放文本任务是否不同？同源和异源学生是否不同？
- How：固定总验证调用数，比较固定复用、角色分离、跨家族轮换，并用永不参与训练的盲验证器和 OOD 集评估。

### 苏格拉底追问

1. 我们把“被固定验证器接受”误当成“真实质量”了吗？
2. 如果只是验证器静态有偏，为什么偏差会随轮次扩大而不是保持不变？
3. 轮次效应也可能来自学生自生成坍缩或连续后训练表征压缩，怎样排除？
4. 若轮换有效，是因为误差去相关、平均能力更强，还是因为目标变得更难投机？
5. 角色分离要付出多少调用成本；等预算后仍有收益吗？
6. 哪个结果会推翻主假设？——固定复用和角色分离在盲分数差距及随轮次斜率上都无稳定差异。

## Stage 3：QFT 扩展与 STORM

QFT 阶段先只生成、不评分，得到 12 个原始问法：

1. 同一验证器多轮筛选会不会让学生学会验证器口味？
2. 同一个模型同时做过滤、课程选择和早停会不会形成信息泄漏？
3. 跨家族轮换验证器能否减小闭环分数与盲分数差距？
4. 验证器自然语言理由会不会把可投机特征直接泄漏给学生？
5. 语义等价变换上的评分违例能否在训练前预测 reward hacking？
6. 自验证代理任务的分数在什么条件下能迁移到原开放任务？
7. 奖励梯度尖锐度能否比 KL 更早预警 hacking？
8. 每轮随机改写等价评分规约能否防止固定边界被学习？
9. 被验证器低置信度拒绝的边界样本是否恰好承载新知识？
10. 依据同一验证器早停是否系统性高估多轮收益？
11. 连续后训练的顺序效应究竟来自表征坍缩还是数据选择偏差？
12. 主动合成准则在不同 checkpoint 上是否保持排序稳定？

STORM 从六种角色扩展和质疑：

- 数据策展者：关心固定调用预算下，轮换是否减少可用数据量和标签一致性。
- RL 优化研究者：指出问题可能只是普通代理过优化，应与 KL、梯度正则作竞争基线。
- 验证器研究者：强调跨家族平均准确率与误差相关性必须分开测量。
- 统计学审稿人：要求预注册盲验证器，不能在看到盲结果后继续调筛选器。
- 小算力实验者：要求先做 SFT 合成闭环，确认机制后再扩展到 RLVR。
- 反方审稿人：指出自然语言任务没有“真值”，至少应同时报告可执行任务、异源 judge 与小规模人工锚点。

## Stage 5：双向钢人与竞争假设

### 主假设的钢人

固定验证器不仅提供标签，还决定哪些样本进入下一轮、哪些难度被继续生成、何时停止训练。每一次选择都改变下一轮数据分布，因此误差并非独立噪声，而会被闭环放大。已有“知识中心”、代理过优化、跨家族 verifier gain 和自适应 holdout 理论共同支持这一机制。

### 最强反方的钢人

现实系统中强验证器错误率可能很低；数据生成器和学生并不能直接观察评分边界；自然分布变化、表示坍缩和教师样本同质化足以解释多轮退化。轮换验证器还可能引入不一致标签，使训练更差。已有 QA 研究甚至未发现长期 benchmark 复用必然导致自适应过拟合。因此不能把任何闭环退化都归咎于验证器复用。

### 竞争假设（ACH）

| 假设 | 预测 | 最能区分的证据 |
|---|---|---|
| H1 适应性验证器复用 | 固定复用的闭环分数继续升高，但盲分数增益斜率转负；角色分离缩小差距 | 轮次 × 方案对盲测差距的交互 |
| H2 普通合成坍缩 | 所有方案都随轮次类似退化，是否轮换验证器影响很小 | 无验证筛选/人工规则筛选也出现同斜率 |
| H3 连续后训练表征坍缩 | 退化与表征秩/各向异性更相关，角色分离无效 | 匹配数据后，表征指标预测盲测退化 |
| H4 标签不一致成本 | 轮换反而更差，且差异由验证器间分歧率解释 | 统一校准后轮换收益消失 |

## Stage 7：前三候选的现实碰撞与反证

### C01：保留

机制级检索没有找到同时具备以下四点的直接工作：LLM 迭代合成后训练、同一验证器跨角色复用、独立盲验证器测量随轮次差距、等调用预算的角色分离/跨家族轮换。最接近的工作分别只覆盖知识中心、主动合成、跨家族 verifier gain 或代理过优化。

反证压力：如果固定复用与角色分离的盲分数曲线无差异，或者差异完全由验证器平均准确率解释，则核心新机制不成立。

### C02：缩小后保留为备选

同构扰动训练已经在归纳推理任务中直接减少 shortcut，所以不能再问“同构验证是否有效”。缩小后的问题只问：**训练前的变换违例率能否跨任务预测未来 hacking**，并与梯度尖锐度、KL 和静态准确率比较。

### C06：保留为备选

大量流程会生成验证理由或 critique，但未找到直接隔离“仅标签、错误定位、完整自然语言理由”三种反馈通道，并在独立验证器上测量验证器风格迁移的研究。这个问题便宜、机制清晰，但影响面略窄于 C01。

## Stage 8：研究问题契约

### 最终问题

在迭代式合成数据后训练中，当同一个验证器被反复用于样本筛选、课程选择和停止判断时，模型在独立验证器与分布外任务上的真实增益会随轮次下降多少；在相同验证预算下，把这三个角色分离并在不同模型家族间轮换，能否阻止这种闭环过拟合？

### 概念边界

- “同一验证器复用”：同一模型家族与同一评分规约至少承担过滤、选择、早停中的两个角色。
- “闭环过拟合”：管线内分数上升，但预先冻结、从不参与训练决策的盲验证器或 OOD 任务增益下降。
- “角色分离”：过滤、课程/数据选择、停止判断由彼此不共享反馈历史的验证器承担。
- “等预算”：每轮总验证 token/调用数保持一致，不允许多验证器方案偷加算力。
- 首轮范围：小模型 SFT 合成闭环；只有发现明确效应后才扩展到 GRPO/RLVR。

### 竞争答案与行动

- A：固定复用显著扩大闭环—盲测差距，角色分离能在等预算下减小。行动：把验证器角色隔离设为合成管线默认，并扩展到 RLVR。
- B：差距很小或角色分离无效。行动：保留单验证器，优先投资数据量、静态准确率或优化正则。
- 未确定：只在同源学生、开放任务或后期轮次出现。行动：把结论缩窄为边界条件，不作通用方法主张。

### 最小可行实验

1. 选择一个 1B–3B 开放学生模型，两类任务：一类有可执行真值（数学/代码），一类开放文本任务。
2. 固定教师、初始种子集、每轮保留数据量、训练 token 和总验证调用数，连续做 3 轮合成 + SFT。
3. 三个方案：
   - 固定复用：同一验证器负责过滤、选择和早停；
   - 角色分离：三个异源验证器分别负责三个角色；
   - 随机轮换：同样三者每轮换角色，用于区分“家族多样性”和“职责隔离”。
4. 在实验前冻结一个永不参与管线的盲验证器、可执行单元测试和 OOD 集；不得根据盲结果继续调方案。
5. 主指标：每轮管线内分数减盲分数的差距及其斜率。次指标：验证器间错误相关、样本接受分布、OOD 增益、单位验证成本收益。
6. 至少 3 个随机种子；先用 500–2,000 条/轮确认效应方向，再决定是否扩大。

### 停止/反转条件

- 若三轮后，固定复用相对角色分离的盲测差距斜率差小于预注册最小效应，且跨种子方向不一致，停止“闭环过拟合”主张。
- 若差异由验证器平均准确率完全解释，把问题改写为验证器能力匹配，不再主张角色隔离机制。
- 若只有开放任务出现，缩小到主观验证场景；若只有同源模型出现，缩小到家族相关误差。

## 最终选择

- 主问题：C01 闭环验证器复用偏差。
- 备选 1：C02 等价变换违例的训练前预警价值。
- 备选 2：C06 验证器自然语言理由泄漏。

本轮结论是“值得做一个小试验”，不是“新机制已经被证明”。最大的剩余未知是：三轮小模型 SFT 是否足以产生可测的适应性复用效应，以及开放任务上的盲验证器能否提供足够独立的近似真值。
